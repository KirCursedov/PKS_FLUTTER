# Отчет по проекту
## Наумов Ярослав Денисович, ЭФБО-10-23

### Цель:
Создать мобильное приложение для хранения и управления кулинарными рецептами.

"Cookbook" - это мобильное приложение на Flutter с использованием Firebase, позволяющее пользователям создавать, хранить и редактировать свои кулинарные рецепты. Приложение поддерживает авторизацию, работу с изображениями и синхронизацию данных в облаке.

## Технологический стек

Frontend: Flutter (Dart)

Backend: Firebase

Firebase Authentication (аутентификация)

Cloud Firestore (база данных)

Firebase Hosting (если требуется веб-версия)

## Реализованные функции
1. Аутентификация
Регистрация новых пользователей

Вход в систему

Автоматический вход при повторном запуске

Безопасное хранение сессии

2. Управление рецептами (CRUD)
Create: Добавление новых рецептов с фото

Read: Просмотр списка рецептов и детальной информации

Update: Редактирование существующих рецептов

Delete: Удаление рецептов

3. Работа с изображениями
Выбор фото из галереи устройства

Конвертация изображений в base64 для хранения в Firestore

Отображение фотографий в карточках рецептов

4. Пользовательский интерфейс
Адаптивный дизайн

Интуитивная навигация

Уведомления об успешных операциях

Диалоги подтверждения для критических действий
